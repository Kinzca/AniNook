### 修正与限制

初次运行 `39143827619` 在安装 SDK 时失败：`android-actions/setup-android@v3` 默认请求已经不可用的 `tools` 包。根据实际日志改为显式安装 `platform-tools`，保留后续 API 36 与 Build Tools 36.0.0 安装；修正提交后才获得上述通过结果。没有忽略失败或关闭检查。

构建日志仍有 `announceForAccessibility` 的 API 弃用提示、部分 GitHub action 的 Node 运行时弃用提示；本次它们未导致任务失败。正式发布前按实际依赖升级计划处理。

Lint 的 16 条警告保留且已阅读：9 条目标 SDK/依赖版本提示，1 条 Android 12+ 数据迁移规则提示，1 条占位角色绘制中的 Path 分配提示，4 条 KTX 写法建议，1 条绝对 LEFT 坐标提示。当前固定 SDK 36 是可复现验证基线，不宣称使用最新版本；窗口使用绝对坐标匹配 rawX/rawY 拖动，不为消除 RTL 警告直接更换成 START。占位绘制性能和 Android 系统设备间迁移行为仍需后续检查，未以本轮 Lint 成功证明它们不存在问题。

本机 Windows 的 Gradle 9.1.0 分发包已下载并通过官方 SHA-256 核对，但没有完成 Windows 的 API 36 依赖安装和全套本机构建。本次构建证据来自 CI，不冒充 Windows 本地成功。

Git diff 空白检查、相对 Markdown 链接检查均通过。`gradlew` 已记录为 Git mode 100755，`local.properties` 与 `.idea` 被忽略。
