# AniNook：项目目标与首版范围

更新：2026-10-18。状态：需求基线与首版范围提案。

## 用户已明确的方向

- 项目名称 AniNook，寓意让喜欢的角色走进生活。
- 单人开发，首个平台为 Android，优先原生开发，尽量减少后续返工与维护负担。
- 二次元二维动态立绘，有表情和动作，视觉目标类似 Live2D。
- 动画技术要求免费开源；应用向用户免费开放使用。
- 支持用户导入角色，并希望以后提供分享、下载及玩家自建资源服务器。
- 希望通过 TapTap 分发；当前桌宠产品是否适合该平台、以何种类别提交，尚未核实。

免费使用不自动表示无广告，也不自动表示 AniNook 自身开源。这两项尚未确定。使用开源动画库也不授权任意角色素材的公开传播。

## 当前产品假设

用户愿意让喜欢的角色长期出现在手机上，且能接受它的操作方式、占用空间与功耗。创作者可以通过可复现的制作流程交付可用角色，用户无需开发工具即可导入。两项假设都需要验证。

## 建议首版范围

以下为当前建议，尚未冻结为最终需求：

- 同时显示一只二维角色，先支持本地导入和离线使用。
- 在其他应用上方悬浮；具体显示范围、隐藏策略与触摸区域通过真机体验确定。
- 支持拖动、缩放、显示/隐藏、点击反馈及待机动画。
- 提供基础角色列表和切换；明确提示不兼容或超出资源限制的模型。
- 屏幕关闭时暂停绘制，恢复后能正常显示；处理权限撤销与图形资源重建。
- 只载入角色数据与媒体，不执行用户包内的脚本或原生插件。

首轮不依赖登录或服务器。不把公共社区、上传审核、多角色同屏、手机角色编辑器、AI 对话、跨平台版本或广告接入列为验证的必要条件。这些事项可后续评估，并不代表已经永久取消。

## 角色与内容来源

先寻找允许用于测试的现成 Inochi2D 模型，至少覆盖形变、遮罩、合成和物理。正式默认角色的美术、绑定、来源与分发授权另外确定。原 Unity 3D 资产不能直接充当二维 Inochi2D 模型。

用户导入的具体 INP/INX 内容版本与特性须通过测试确定；不承诺直接导入 Live2D moc3 或任意 3D 模型。

## 验证成功的含义

技术上：从可复现构建到真机导入、正确绘制、互动、悬浮和恢复形成闭环，内存与功耗有测量记录。

产品上：试用者愿意保留桌宠，不频繁因遮挡、耗电或操作负担关闭它；创作者能按照文档制作和导入角色，不依赖逐模型代码修补。

通过技术验证后，重新估算开发周期、资源预算与首版范围。原便利店项目的四周安排、千元预算和广告收入指标不直接沿用。
